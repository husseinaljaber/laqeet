# لقيت (Laqeet): شغل بسوريا على قد شهادتك

موقع (وتطبيق موبايل PWA) بيجمع إعلانات الشغل بسوريا وتركيا من حوالي 90 مصدر، وبيورجي كل واحد الشغل يلي بيناسب شهادته ومدينته:

- **قنوات تلغرام** (حوالي 60 قناة، القائمة بـ `data/channels.json`): وزارة التنمية الإدارية، والوزارات، ووظفني، ومنصة التوظيف، وفرص عمل في سوريا، وغيرها.
- **مواقع التوظيف والمنظمات**: ReliefWeb، وUNjobnet، وImpactpool، وأنظمة التوظيف عند المنظمات (NRC وIRC وDRC…)، ومواقع توظيف سورية وتركية.

## شو بيعمل
- **«شو شهادتك؟»**: أول زيارة 3 أسئلة (الشهادة، المجال لأصحاب الشهادات، المدينة)، وبعدها الوظائف فوراً. الاختيارات بتضل على الجهاز بس، والزيارة الجاية بتفتح على الوظائف مباشرة.
- الإعلان يلي ما ذكر شهادة بيطلع للكل مع «الشهادة مو مذكورة»، بدل ما نخمّن.
- **«بتنطبق عليك؟»** على كل إعلان (أخضر، برتقالي، أحمر) حسب الشهادة والعمر والخبرة.
- **شغل رسمي** (فيه موعد تقديم) و**شغل سريع** (فيه زر واتساب كبير).
- لون حافة البطاقة بيدل على الخبرة المطلوبة، وفي شارة «رسمي ✓» للإعلانات الحكومية.
- زر **«بلّغ»**: الإعلان بيختفي بعد 3 بلاغات لحتى يتراجع.
- **دمج المكرر**: نفس الإعلان المنشور بأكتر من قناة بيطلع ببطاقة وحدة، وتحتها كل المصادر.
- **بوت تلغرام** بيبعت كل وظيفة جديدة بتناسبك مرة وحدة بس.
- **صاحب العمل بينشر إعلانه ببلاش**، والإعلان بيمرق على المراجعة قبل ما ينزل.
- **سيرة ذاتية بالعربي** بتنطبع أو بتنحفظ PDF، وبتعلّم على المطلوب بالوظيفة.
- **نبض السوق**: شو أكتر شي مطلوب حسب المدينة والشهادة والمجال، وكيف عم يتغيّر من شهر لشهر.

## التشغيل على جهازك
```bash
pip install -r requirements.txt
sudo apt install tesseract-ocr tesseract-ocr-ara   # لملفات الوزارة يلي خطها خربان (اختياري)
pytest                                             # الاختبارات
python -m app.collect --offline                    # بناء القاعدة من المنشورات المحفوظة (بدون نت)
python -m app.collect                              # أو سحب المنشورات الجديدة من تلغرام
uvicorn app.api:app --port 8000                    # افتح http://localhost:8000
```
- بعد ما تصلّح شي بالاستخراج: `python -m app.collect --reprocess`
- الشغل بالخلفية (السحب كل 30 دقيقة مع البوت): `python -m app.run`
- البوت لحاله: `TELEGRAM_BOT_TOKEN=... python -m app.bot`
- صفحة المراجعة: `/admin.html` (حط `ADMIN_TOKEN` بالـ `.env`)

- **صحة المصادر:** بصفحة `/admin.html` (تبويب «صحة المصادر») بتشوف أي قناة أو موقع وقف يجيب إعلانات. وإذا حطيت `ADMIN_CHAT_ID` (رقم محادثتك مع البوت)، البوت بيبعتلك ملخص مرة باليوم إذا في مصدر خربان.
- **Google for Jobs:** كل صفحة وظيفة مفتوحة `/j/<id>` فيها بيانات `JobPosting`، وفي `/sitemap.xml` و`/robots.txt`. بعد ما تربط الدومين، حط `PUBLIC_URL` وضيف الموقع على Google Search Console وابعتله الـ sitemap.
- **AI اختياري:** إذا حطيت `ANTHROPIC_API_KEY`، الإعلانات يلي القواعد ما قدرت تقراها منيح بتنبعت للـ AI (موديل صغير ورخيص، `LLM_MODEL`)، بحد أقصى `LLM_DAILY_LIMIT` طلب باليوم. أرقام التلفون والروابط دايماً بتنسحب من النص نفسه، مو من الـ AI. بدون مفتاح كل شي بيشتغل متل قبل.

- **قنوات تلغرام لكل مدينة:** البوت بينشر كل وظيفة جديدة بقناة مدينتها:
  1. اعمل القنوات (عامة) من تلغرام، مثلاً `@laqeet_damascus`، `@laqeet_aleppo`، `@laqeet_syria`، `@laqeet_turkey`.
  2. ضيف البوت تبعك **أدمن** بكل قناة، مع صلاحية النشر.
  3. حط بـ`.env`:
     `CITY_CHANNELS={"دمشق": "@laqeet_damascus", "حلب": "@laqeet_aleppo", "*sy": "@laqeet_syria", "*tr": "@laqeet_turkey"}`
     (`*sy` = كل سوريا، `*tr` = كل تركيا، وفيك تحط بس يلي بدك ياه).
  4. افحص: `python -m app.city_channels --check`، لازم يطلع «تمام» جنب كل قناة.
  5. أول تشغيلة بتسجّل الوقت بس. بعدها كل شي جديد بينزل، كل إعلان مرة وحدة، وبحد أقصى 15 بكل قناة بكل جولة.

الإعدادات كلها بملف `app/config.py`، وفيك تغيّر أي وحدة منها بمتغيّر بيئة (شوف `.env.example`). **اسم المنصة** بتغيّره من `SITE_NAME`.

## النشر على سيرفر (VPS بحدود 5–10 دولار بالشهر)
```bash
cp .env.example .env    # وعبّي القيم
docker compose -f deploy/docker-compose.yml up -d --build
```
هيك بيشتغل `api` (الموقع على البورت 8000) و`worker` (السحب والبوت).

## وين تنحفظ البيانات (مهم)
- **Render المجاني** ما فيه قرص دائم: كل مرة بينعاد النشر، القاعدة بتنبني من جديد من `data/seed_jobs.jsonl.gz`. هيك **إعلانات أصحاب العمل ورموز المتابعة والبلاغات ومشتركين البوت بيروحوا**. والبوت ما بيشتغل هونيك أصلاً.
- الـ workflow بـ GitHub بيحدّث الـ seed **مرة باليوم** (وفيك تشغّله بإيدك من تبويب Actions).
- الحل الدائم: VPS مع `docker compose` (فوق)، القاعدة بتنحفظ بالـ volume `laqeet-data`. أو Render مدفوع مع disk. أو Postgres خارجي (بدو تعديل أكبر بطبقة القاعدة).

## ربط دومين
1. اشتري الدومين، وحطّه على Cloudflare (ببلاش).
2. ضيف سجل `A` بيأشّر على عنوان الـ IP تبع السيرفر، وخلّي الغيمة البرتقالية (Proxy) شغّالة.
3. من Cloudflare، بقسم SSL/TLS، اختار **Full**. بعدها حط Caddy أو nginx على السيرفر ليحوّل الطلبات من البورت 443 للبورت 8000.
4. حط `PUBLIC_URL=https://دومينك` بملف `.env`.

## قبل الإطلاق (قائمة)
**قرارات بإيدك:**
- [ ] **الاستضافة الدائمة** (أهم شي): VPS مع `docker compose`، أو Render مدفوع مع disk. بدونها إعلانات أصحاب العمل والبلاغات ومشتركين البوت والإحصائيات بتضيع.
- [ ] **الاسم والدومين:** تأكد إنه «لقيت» مو علامة تجارية مسجّلة، واشتري الدومين.
- [ ] **WhatsApp Business API** (اختياري): للتنبيهات وتوثيق أصحاب العمل. فيه كلفة.
- [ ] **مفتاح AI** (اختياري): `ANTHROPIC_API_KEY`. جرّبه على كم إعلان قبل ما تعتمد عليه.

**إعدادات (`.env`):**
- [ ] `ADMIN_TOKEN` طويل وعشوائي (مثلاً `python -c "import secrets;print(secrets.token_urlsafe(32))"`).
- [ ] `PUBLIC_URL=https://دومينك`، لأنه روابط المشاركة والـ sitemap وGoogle بيعتمدوا عليه.
- [ ] `TELEGRAM_BOT_TOKEN` و`ADMIN_CHAT_ID` لتنبيهات البوت وتنبيه المصادر الخربانة.

**بعد ما يشتغل:**
- [ ] افتح `/api/health` و`/admin.html` (كل التبويبات).
- [ ] Google Search Console: ضيف الدومين وابعت `/sitemap.xml`.
- [ ] نسخة احتياطية: زر «نسخة احتياطية» بالإدارة، أو `python -m app.backup export backup.json.gz`. خليها برا GitHub لأنه فيها أرقام أصحاب العمل. للاسترجاع: `python -m app.backup import backup.json.gz`.
- [ ] راسل أدمنية القنوات من تبويب «الشركاء» (الرسالة جاهزة بالأرقام).
- [ ] تأكد إنه تبويب «صحة المصادر» ما فيه «أخطاء».
- [ ] إذا الـ repo عام: إيميلك لسا بتاريخ الـ commits القديمة. فكّر تعمل repo جديد نظيف أو تخليه خاص.

**تطبيق Play Store (لما تكون جاهز):**
1. نزّل [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap): `npx @bubblewrap/cli init --manifest https://دومينك/manifest.webmanifest`.
2. `npx @bubblewrap/cli build`. بيعطيك ملف `.aab` وبصمة المفتاح (SHA-256).
3. حط بـ `.env`: `TWA_PACKAGE=اسم الحزمة` و`TWA_SHA256=البصمة`، فبيصير الموقع يقدّم `/.well-known/assetlinks.json` لحاله.
4. ارفع الـ `.aab` على Google Play Console (حساب المطوّر 25$ مرة وحدة).

**الاختبارات:** بتشتغل لحالها على GitHub مع كل push (`.github/workflows/tests.yml`). محلياً: `pytest`.

## التطبيق (Flutter) والحسابات

التطبيق بمجلد `mobile/`: أندرويد وآيفون وويب من نفس الكود. بيحكي مع نفس السيرفر عن طريق `/api/v1`.

- **الحساب:** اسم، كنية، جنس، إيميل وكلمة سر يختارها الشخص. بيوصله كود من ٦ أرقام على الإيميل ليأكّده. فيه «نسيت كلمة السر» وتغيير كلمة السر وحذف الحساب من جوّا التطبيق (المتاجر بتطلبه).
- **بعد التسجيل:** ٣ أسئلة (الشهادة، المجال، المدن) وبعدين «مناسبة إلك» بتفرز الوظائف عليها. فيك تتصفح بلا حساب كمان.
- **التقديم:** واتساب برسالة جاهزة باسم الشخص، اتصال، إيميل برسالة رسمية، أو رابط الإعلان. والوظيفة بتنحفظ تلقائياً «قدّمت».
- **محفوظاتي:** متابعة كل وظيفة (محفوظة ← قدّمت ← مقابلة ← عرض ← ما زبطت).

**لازم قبل ما تفتح الحسابات للناس:**
1. `SECRET_KEY` بـ `.env` (سطر طويل عشوائي: `python -c "import secrets;print(secrets.token_urlsafe(48))"`). إذا تغيّر، كل الناس بيطلعوا من حساباتهن.
2. إعدادات الإيميل `SMTP_HOST/SMTP_PORT/SMTP_USER/SMTP_PASSWORD/MAIL_FROM`. بلاها الأكواد بتنكتب بسجل السيرفر بس (وضع التطوير).
3. **تخزين دائم.** الحسابات ما بتعيش على Render المجاني (القرص بينمسح). لازم VPS مع volume أو قرص مدفوع.
4. حط إيميل تواصل بصفحة `frontend/privacy.html`.

**التشغيل للتطوير:**
```bash
cd mobile && flutter pub get && flutter test
flutter run --dart-define=API_BASE=http://IP-جهازك:8000
```

**نسخة الويب:** `cd mobile && flutter build web --release --base-href /app/ --no-web-resources-cdn` والسيرفر بيقدّمها على `/app` لحاله. (`--no-web-resources-cdn` مهم: بلاه المتصفح بيحمّل محرك الرسم من جوجل، وهاد ممكن يكون محجوب أو بطيء بسوريا.)

**APK:** كل تعديل على `mobile/` بيبني APK على GitHub Actions (ملف `.github/workflows/mobile.yml`)، وبتلاقيه بـ «Artifacts» تبع التشغيل. حط متغير المستودع `API_BASE` بعنوان السيرفر الحقيقي. للنشر على Google Play لازم مفتاح توقيع خاص (upload keystore) بدل مفتاح التجربة. معرّف التطبيق `com.laqeet.app` وما بيتغيّر بعد أول نشر.

## الملفات
- `app/sources/telegram.py`: بيقرا القنوات من `t.me/s/<channel>`، بفاصل ثانية على الأقل بين كل طلب.
- `app/extract.py` و`app/taxonomy.py` و`app/spam.py`: بيستخرجوا الوظائف من المنشورات بقواعد مكتوبة.
- `app/sources/moad_pdf.py`: بيقرا بطاقات الوصف من ملفات PDF تبع الوزارة (ومعه OCR).
- `app/collect.py`: الجامع. `app/db.py`: قاعدة البيانات (SQLite، وفيك تنقلها لـ Postgres بسهولة).
- `app/api.py`: الـ API. `app/bot.py`: البوت. `app/run.py`: الجدولة.
- `frontend/`: الموقع وتطبيق الـ PWA.
- `tests/`: الاختبارات، ومعها منشورات حقيقية مصنّفة بالإيد (`tests/real/gold.py`).

## الأخلاقيات
- منذكر المصدر دايماً، ومنحط رابط الإعلان الأصلي، والتقديم بيصير من الرابط الأصلي.
- منسحب بهدوء (ثانية على الأقل بين كل طلب).
- أرقام التلفون يلي بالإعلانات حطّها المعلنين للمتقدمين، فزر الواتساب ما فيه مشكلة. وما منجمع أي شي تاني عن حدا.
- قبل ما يصير الموقع عام: لازم نقرا شروط موقع الوزارة، ونحكي مع أدمنية القنوات ونعرض عليهم ذكر اسمهم ونبعتلهم زوار.
